# レビュー精読メモ（記入テンプレート）

このメモが、このサイトの「他所に無い情報」の中身になる。実物を買わず・走らずに、
既存レビューを人が読んで傾向を記録する。**AIはAmazonを取得できない**（robots.txtで
ClaudeBot等を全面拒否）ため、ここは人の作業になる。1商品あたり5〜10分。

## 書くときの絶対ルール

- **「実測した」と書かない。** 根拠は「レビューN件を読んだ傾向」であって実測ではない。
  記事側でも `根拠: レビュー精読` と明示する。混同はステマ規制・景表法の事故になる。
- **件数を必ず書く。** 「小さめとの声が多い」ではなく「低評価20件中12件がサイズ感」。
  数が無い印象論は書かない。
- **不満は原文の言い回しを要約して残す。** 「幅が狭い」と「甲が高いと当たる」は別の情報。
- **★1だけでなく★2〜3も読む。** ★1は配送事故や個体不良が混ざり、商品の傾向が出にくい。
- **サクラ疑いを飛ばす。** 同日に集中、極端に短い絶賛、日本語が不自然なものは数えない。

## 記入後の流れ

1. このメモを `data/review-notes/<商品スラッグ>.md` として保存
2. Claude Code が公式スペックと突き合わせ（上記の「公式情報との突き合わせ」欄を埋める）
3. Codex が記事化。レビュー由来の記述には根拠の種類を明記
4. 楽天APIの `reviewCount` / `reviewAverage` による定量表と並べて掲載
